# капибары
капибары и их особенности
Кто такая капибара? Это полуводное травоядное млекопитающее из подсемейства водосвинковых. Латинское название животного Hydrochoerus hydrochaeris переводится как ‘водяная свинья’. На сайте Всемирного фонда дикой природы капибару называют самым крупным современным грызуном.
